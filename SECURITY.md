# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

CareSync prioritizes patient data safety and privacy.
If you discover a security vulnerability or client data leakage concern, please do not file a public issue.

Instead, please report it privately:
* Email: security@caresync.org or jayashree@example.com
* Include detailed reproduction steps and affected components.

We will acknowledge receipt within 24 hours and provide an update on remediation timelines.
